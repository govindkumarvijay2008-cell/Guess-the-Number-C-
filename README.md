# Guess the Number (C++)

The program chooses a random number from 1 to 100. The player guesses until the answer is correct and receives higher/lower hints and an attempt count.

## Compile and run
```sh
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o guess-number
./guess-number
```
On Windows, run `guess-number.exe` after compilation.
